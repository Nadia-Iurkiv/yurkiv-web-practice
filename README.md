# yurkiv-web-practice
# 📚 UniBook — Студентська платформа обміну підручниками

Вебплатформа для студентів, яка дозволяє легко обмінюватися, знаходити або віддавати даром навчальні підручники та методичні матеріали.

## 🛠 Технологічний стек
* **Клієнтська частина (Frontend):** React, JavaScript, HTML5, CSS3.
* **Серверна частина (Backend):** Node.js, Express.js.
* **Система контролю версій:** Git, GitHub.

## 📁 Структура проєкту
* `client/` — Клієнтська частина застосунку на React (компоненти, інтерфейс каталогу).
* `server/` — Серверна частина та REST API (Node.js/Express).
* `docs/` — Технічна документація (`TZ.md` — технічне завдання, `UI.md` — дизайн та прототипи).

## ✨ Основні можливості
* Перегляд каталогу доступних підручників у вигляді карток.
* Фільтрація за станом книг та типом угоди (обмін, продаж, даром).
* Базовий REST API для отримання даних про підручники.
