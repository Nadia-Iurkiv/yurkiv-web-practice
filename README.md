# yurkiv-web-practice
# 📚 UniBook — Студентська платформа обміну підручниками

Навчальний вебпроєкт для практики. Сайт допомагає студентам легко знаходити, обмінюватися чи віддавати даром навчальні підручники та методичні матеріали.

## 🚀 Можливості
* Головна сторінка з описом платформи та каталогом.
* Каталог підручників із фільтрами за станом і типом угоди (обмін, продаж, даром).
* Форма додавання нового підручника з клієнтською валідацією.
* Адаптивна навігація та сучасний дизайн інтерфейсу.
* REST API на Node.js/Express.

## 🛠 Технології
React, Node.js, Express, CSS, Git, GitHub.

## 📁 Структура проєкту
* `client/` — Клієнтська частина застосунку на React.
* `server/` — Серверна частина та REST API (Node.js/Express).
* `docs/` — Технічна документація (`TZ.md`, `UI.md`).
