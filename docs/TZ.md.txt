# Технічне завдання (ТЗ)
## Проєкт: Студентський букініст — платформа обміну підручниками між студентами

### 1. Аналіз предметної області та конкурентів
1. **OLX (категорія «Книги / Журнали»)**
   - *Сильні сторони:* велика аудиторія, зручне завантаження фото та прямий зв'язок через повідомлення.
   - *Слабкі сторони:* відсутня фільтрація за навчальними дисциплінами чи курсами, багато сторонньої художньої літератури.
2. **Університетські та коледжівські чати у Telegram**
   - *Сильні сторони:* цільова аудиторія з одного навчального закладу, швидка особиста передача книг.
   - *Слабкі сторони:* немає структурованого каталогу та пошуку за предметами, старі неактуальні оголошення не видаляються.
3. **Онлайн-букіністи та книгарні (наприклад, Yakaboo, IZI)**
   - *Сильні сторони:* зручний каталог та сортування за параметрами.
   - *Слабкі сторони:* відсутність функції прямого обміну (бартеру) між студентами, складна форма додавання товару.

### 2. Призначення, цільова аудиторія та сценарії використання
- **Мета сайту:** створити спеціалізовану вебплатформу, де студенти можуть швидко знаходити потрібні підручники, публікувати власні оголошення з реальними фотографіями книг для продажу чи обміну та напряму зв'язуватися з власниками.
- **Цільова аудиторія:** студенти коледжів, технікумів та університетів віком 16–23 роки.
- **Ключові сценарії використання:**
  1. *Пошук підручника:* студент вводить назву книги чи дисципліни в пошук, фільтрує результати та знаходить потрібне оголошення.
  2. *Публікація оголошення:* користувач відкриває форму додавання, завантажує фото обкладинки підручника, вказує стан, тип угоди (обмін/продаж) та свої контакти.
  3. *Перегляд деталей:* користувач відкриває сторінку конкретної книги, переглядає фото та детальний опис стану сторінок перед зв'язком із власником.

### 3. Структура сторінок (Карта сайту)
- `/` — **Головна сторінка:** опис сервісу, рядок швидкого пошуку, блок останніх доданих підручників.
- `/catalog` — **Каталог оголошень:** повний список карток підручників із фільтрацією за предметами, типом угоди та сортуванням.
- `/books/:id` — **Сторінка деталей оголошення:** велике фото книги, автор, предмет, стан, опис, контакти власника, кнопка видалення.
- `/add` — **Сторінка додавання оголошення:** інтерактивна форма створення оголошення із завантаженням фотографії.
- `*` — **Сторінка 404:** повідомлення про неіснуючу сторінку з кнопкою повернення в каталог.

### 4. Функціональні вимоги
1. Відображення списку всіх актуальних оголошень у вигляді адаптивних карток із фото.
2. Пошук підручників за назвою та автором у реальному часі.
3. Фільтрація каталогу за навчальною дисципліною (Програмування, Математика, Історія, Іноземна мова тощо) та типом угоди (Обмін / Продаж / Безкоштовно).
4. Перегляд детальної інформації про обраний підручник на окремій сторінці.
5. Створення нового оголошення через форму з обов'язковим прикріпленням фотографії книги.
6. Клієнтська та серверна валідація полів форми (перевірка обов'язкових полів, формату зображення та контактних даних).
7. Можливість видалити неактуальне оголошення.
8. Перемикання світлої та темної теми оформлення інтерфейсу.

### 5. Нефункціональні вимоги
- **Адаптивність:** верстка за принципом mobile-first із коректним відображенням на екранах 360 px, 768 px та 1280 px.
- **Швидкодія та якість:** показники аудиту Google Lighthouse (Performance, Accessibility, Best Practices, SEO) $\ge 90$ балів.
- **Доступність (a11y):** повна навігація з клавіатури, видимий фокус елементів, наявність атрибутів `alt` для всіх фотографій підручників, достатній контраст тексту.

### 6. Стек технологій
- **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Variables), JavaScript (ES6+), React, Vite, React Router.
- **Backend:** Node.js, Express, збереження даних у JSON-файлі (`fs/promises`) або SQLite, обробка завантаження файлів.
- **Інструменти розробки:** Git, GitHub, Figma, Postman, Vitest, Vercel / Render.
