# UX/UI Проєктування: Вебплатформа «UniBook»

## 1. Візуальний стиль (UI Kit)
* **Основна колірна гама:**
  * Фон сторінок: `#F8FAFC` (світло-сірий, комфортний для читання)
  * Картки та шапка: `#FFFFFF` (білий із легкою тінню)
  * Основний акцент (кнопки, посилання): `#2563EB` (насичений синій)
  * Додатковий акцент (позначки «Даром» / «Обмін»): `#16A34A` (зелений)
  * Основний текст: `#1E293B` (темно-графітовий)
* **Шрифт:** `Inter` або системний sans-serif.
* **Адаптивність:** Mobile-first (1 колонка на мобільних екранах, 3–4 колонки в сітці каталогу на ПК).
