# Технічне завдання: Веб-платформа «UniBook — Обмін підручниками між студентами»

## 1. Мета проєкту
Створення вебплатформи для студентів задля зручного пошуку, обміну та передачі вживаних навчальних підручників і методичок.

## 2. Структура сторінок
1. **Головна** — банер, короткий опис, останні оголошення.
2. **Каталог** — список усіх підручників із пошуком та фільтрами.
3. **Деталі** — сторінка конкретної книги з повною інформацією та контактами.
4. **Створити оголошення** — форма для додавання нової книги з фото.

## 3. Основна сутність (CRUD)
* **Оголошення (Item):** назва книги, автор, дисципліна, стан, тип угоди (обмін/даром), ціна, опис, фото, контакт власника.
